# Кадровый кабинет HR

Демонстрационный русскоязычный сайт для подбора кандидатов и приёма сотрудников.

## Запуск

Откройте `index.html` в браузере. Сайт не требует установки зависимостей или сборки.

## Возможности

- Панель HR с этапами воронки и открытыми вакансиями.
- Карточки кандидатов, фильтры и смена этапа подбора.
- Форма приёма сотрудника и чек-лист оформления.
- Персональная ссылка на портал кандидата: мини-тест, опрос, выбор документов и просмотр оффера.
- Настраиваемые контакты работодателя.

## Ограничения демо

Данные хранятся в локальном хранилище браузера. Файлы не загружаются: сайт запоминает только их названия. Демо-ссылки и ответы не синхронизируются между устройствами. Для рабочего развёртывания нужны защищённый сервер, аутентификация, защищённое хранилище документов и проверка текстов о персональных данных.

Не используйте настоящие персональные данные или документы в этой демонстрационной версии.
